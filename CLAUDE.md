# CLAUDE.md

Правила для Claude Code в ЯЗС-Студии. Подробности - в `docs/` (таблица в `README.md`). Здесь - то,
что ломается молча, если о нем забыть.

## Проект

Музыка для ячейки звукового синтеза 5/2 (ЯЗС) Агата-9:
- плеер на 6502 (`player/`, AS65);
- формат `.YZ` v1/v2 (`docs/FORMAT.md`);
- инструменты на Python (`studio/`): компилятор партитур `compose.py`, модель движка `pyplay.py`,
  сборка диска `build.py`, прослушивание и сверка через эмулятор, конвертер SID.

Испытательный стенд - эмулятор eCat3 рядом (`../eCat3`), его консольная сборка и MCP-сервер `ecat3`
(`docs/ecat3.md`).

## Команды

```
python studio/checks.py --quick          суммы партитур и v1/v2 на модели (секунды)
python studio/checks.py                  + процессор SID и плеер в eCat3 против модели (~40 с)
python studio/checks.py --update         записать суммы после намеренной правки музыки
python studio/test_v2.py m4_blues        v1/v2 на модели - одна партитура
python studio/verify.py test_fx          плеер в eCat3 против модели - одна мелодия
python studio/sid/test_cpu.py            только процессор конвертера SID (~30 с)
python studio/listen.py m5_synth --mp3   WAV/MP3, уровни, запас тика, потерянные тики
python studio/build.py --only test_fx --disk out/dev.dsk --no-hfe    диск для отладки
```

Остальные инструменты - таблица в `docs/development.md`. Модули `studio/` импортируют друг друга
как соседние (`import build`), пакета нет: скрипт вне `studio/` (в `out/`) добавляет его в `sys.path`.

## Как устроено

- **Партитура** `studio/score/<имя>.py` - функция `song()`, возвращает `compose.Song`;
  `Song.build()` дает байты `.YZ`. Грузит ее `build.load_score(имя)`. `common`, `instruments`,
  `data_*` - не партитуры, `checks.py` и `test_v2.py` их пропускают.
- **Новая пьеса:** модуль в `score/`, строка в `SONGS` (симфония) или `COLLECTION` в `build.py`,
  `checks.py --update` (в отчете она «новая»), статус прав - `docs/music.md`.
- **`build.py`:**
  1. `tables.py` и строки интерфейса -> `player/gen_tables.a65`, `gen_const.a65`. Они
     перезаписываются каждой сборкой: руками не править.
  2. AS65 собирает `player/player.a65` (включает `engine`, `disk`, `ui` -> `tracker`) в плеер с
     `$1800`, листинг - `out/build/player.lst`. Перед телом - `loader.a65`: файл `ЯЗС-ПЛЕЕР`
     грузится с `$4000`, загрузчик кладет тело на `$1800` (так же работает BRUN из ДОС,
     `docs/player.md`).
  3. Плеер и `.YZ` ложатся на копию `disk/template840.dsk` (`mkdisk840.py`) -> `dist/`.
  4. `.hfe` пишет eCat3 через `render.py`.
- **`tables.py`** - общий источник таблиц периодов и вибрато для плеера (через `gen_tables.a65`) и
  модели `pyplay.py`, частоты таймера - для `compose.pick_speed`. Ошибку в нем сверка плеера с
  моделью не поймает: она будет в обоих.
- **Адреса переменных плеера зашиты снаружи:**
  - `verify.py`: `$1E`, `$09E8`, `$09F0`, `$09F8`;
  - тест eCat3: `$1E`, `$14`, `$4D`.

  Перенесли переменную - поправьте и их.
- **`score/data_*.py`** сгенерированы `studio/importers/gen_*.py` из MIDI/LilyPond в
  `docs-external/` (не в git). Руками не править: оркестровка - в `score/<имя>.py`.
- **Конвертер SID:**
  - `sid2yz.py` -> `sid/`: свой эмулятор 6502 и окружение C64 гоняют проигрыватель мелодии;
  - `convert.py` ставит команды прямо в строки (`Song.put`, строка - кадр SID);
  - после перевода `pyplay` сверяет высоту с регистрами SID.

## Общие правила

- **Язык документации и комментариев - русский.** Шапка исходников -
  `SPDX-License-Identifier: GPL-3.0-or-later` и строка про YAZS Studio.
- **Коммиты - только по просьбе.** Изменения остаются в рабочем каталоге, коммитит владелец.
- **Python** - `C:\DEV\venv\Scripts\python.exe` (numpy, scipy, matplotlib, Pillow).
- **Окончания строк - родные:** на Windows CRLF, в репозитории LF (`.gitattributes`). Скрипты пишут
  текст без `newline=`, Python ставит родные окончания сам. Edit сохраняет CRLF, а Write создает
  новый файл с LF: после создания перевести его в CRLF.
- **Heredoc в Bash портит обратные косые черты и иногда кавычки.** Код со слэшами и длинные патчи
  писать файлом (Write) и запускать.
- **Скачивание** - только с явного согласия, по файлу: имя, источник, размер. Проверки от роботов
  (IMSLP) не обходить: файл скачивает владелец.
- **Авторские права:**
  - охраняемые мелодии не транскрибировать;
  - переводы SID - чужая музыка, в репозиторий и на диски для публикации не класть;
  - статус пьес - `docs/music.md`.
- **Временные файлы** - в `out/` (не в git) или во временном каталоге сессии, не в `studio/`.

## Движок и формат

- **Порядок правки движка:**
  1. `studio/pyplay.py` (модель);
  2. `player/engine.a65`;
  3. `studio/verify.py` (плеер против модели тик в тик) на `test_fx` и мелодии с эффектом;
  4. `docs/FORMAT.md`;
  5. если поле новое, `compose.py`.

  Новые эффекты - в `score/test_fx.py`.
- **`studio/checks.py`** - после любой правки `compose.py`, инструментов, движка. Суммы партитур
  (`tests/scores.md5`) не должны меняться молча: v1 собирается байт в байт. Если `eCat3-headless` не
  найден, шаг [4] пропускается, а итог все равно «ВСЕ ПРОВЕРКИ ПРОШЛИ»: смотреть строку [4].
- **Версия 1 формата не меняется** (старые файлы на дисках). Новое - через версию в заголовке.
  `compose.py` пишет самую младшую подходящую версию.
- **AS65:**
  - `hi(X)+n` - это `hi(X+n)`: страницы задавать константами;
  - короткие переходы ±127 байт;
  - плеер - до `$3EFB` (загрузчик копирует тело целыми страницами), нулевая страница занята до
    `$86`;
  - код выхода в ДОС (`dos_exit`) - вне страницы `$1800-$18FF`: он ее восстанавливает.
- **Плата ЯЗС** (`docs/card.md`):
  - повторный удар только после D4 = 0 на тик (движок делает сам);
  - тик выше ~110 Гц при 5 каналах не укладывается;
  - полосы (особенно ВЧ) не переключать каждый тик: щелчки;
  - три голоса с D3 и ударный 6 с D3 перегружают смеситель.
- **Для настоящего железа:**
  - SEI и опрос флага таймера;
  - `+F = $C0` в начале и на выходе;
  - чужие слоты не читать;
  - `$D000+` не трогать;
  - при ДОС (BRUN) не трогать `$0300-$05FF`, `$0600-$0FFF` и страницу `$18` - только с
    сохранением, банки 8-15 - нет;
  - выход - к запустившему: RTS в «Быстропускалку», теплый перезапуск ДОС `JMP $03D0`
    (`docs/player.md`).

## eCat3

- **Сценарии** гоняет `studio/render.py`: консольный eCat3 в своем рабочем каталоге `out/.../work` с
  копией `.ecat.ini`. `deploy/ecat.ini` eCat3 не трогать.
- **`WAIT` считает эмулированное время:** не загрузилась машина - ждет вечно. В MCP ставить
  `timeout_ms`. Снимки экрана - при остановленном процессоре (`COMMAND cpu.stop()`).
- **«Потеряно N тиков»** в первые секунды у больших файлов - загрузка с диска, не перегруз
  (`studio/lostticks.py`).
- **Диск библиотеки eCat3** (`library/agat/yazs-player.dsk`) и тест `work-agat-9-yazs-player`:
  - `studio/build.py --to-ecat3`, затем тест в eCat3 (`docs/ecat3.md`);
  - эталоны перезаписываются там, коммит - в eCat3;
  - модель ячейки - код eCat3, правится по правилам его `CLAUDE.md`.
