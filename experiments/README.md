# Опыты

Скрипты, которыми проверялись идеи. Они не входят в сборку и проверки, лежат для истории и
повторения. Пути к `studio/` поправлены после переноса. Входные записи (WAV, сценарии с их
результатами) остались во временных каталогах сессий и сюда не перенесены. Перед запуском
посмотрите, что скрипт ждет на входе.

| Каталог | Что |
|---|---|
| `warm/` | «Теплая» версия симфонии - ниже и темнее, ближе к звучанию демо НКЛ. `warm.py build` / `listen` переделывает основные партитуры на лету (октавы, полосы, ударные без D3) и собирает `dist/yazs-player-warm.dsk`. `build_ab.py` - диск A/B `dist/yazs-player-ab.dsk`: у каждой части рядом ее теплая версия, в конце все пьесы. `post.py` - сравнение по меркам. Работают после переноса, тёплые `.yz` совпадают с ноябрьскими |
| `demo-ncl/` | Симфония против демо НКЛ (`music-d.dsk`) по одним меркам: доли регистров, полосы, огибающие, микровысота, удвоения, ударные, громкость, спектральный центр. `compare.py` - главный, остальное - нарезка записи (`cut.py`), корреляция (`corr.py`), фразы (`phrases.py`), запись (`rec.py`, `*.ecat`), трасса регистров (`trace.py`) |
| `timbre/` | `harm.py`: гармоники тона ЯЗС по полосам и высотам, режим 2 счетчика, наложение октавы |
| `bumblebee/` | `bee_variants.py`: варианты инструмента «Шмеля» A-D, когда искали причину треска (ответ - переключение ВЧ каждый тик) |
| `misc/` | `concat.py` - склейка частей в одну запись симфонии, `lost.py` - ранний вариант `studio/lostticks.py` |
