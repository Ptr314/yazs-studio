# ЯЗС-Студия

Музыка для ячейки звукового синтеза 5/2 (ЯЗС) Агата-9: трекерный плеер на 6502, формат мелодий
`.YZ`, компилятор партитур на Python, конвертер мелодий Commodore 64 (SID) и сборка дисков для
Агата-9 с дисководом 840 КБ — в эмуляторе [eCat3](https://github.com/Ptr314/ecat3) и на настоящей
машине.

Проект выделен из eCat3 (`tools/yazs-player`) в ноябре 2026 года. Эмулятор остается его
испытательным стендом: звук, снимки экрана и сверка плеера с моделью идут через eCat3
(`docs/ecat3.md`).

## Что есть

- **Плеер** (`player/`, AS65): меню мелодий `*.YZ` с диска, движок формата, вид «пульт» (АЦР-32) и
  «трекер» (АЦР-64), свой драйвер диска 840 КБ. Запускается «Быстропускалкой» с дорожки 0.
- **Формат `.YZ`** версий 1 и 2 (`docs/FORMAT.md`): кадры, паттерны каналов, инструменты с
  макросами по тикам, эффекты. Версия 2 - 16-битные номера и паттерны в верхних 64 КБ ОЗУ, файлы
  до ~88 КБ.
- **Компилятор партитур** (`studio/compose.py`): MML по тактам, инструменты, ударные, темп, свинг,
  подписи на экране.
- **Партитуры** (`studio/score/`):
  - «Симфония А-Г-А-Т» в шести частях и «тур по тембрам» - диск `yazs-player.dsk` в библиотеке eCat3;
  - пьесы в разных стилях (буги, диско, джаз-мануш);
  - переложения классики (Григ, Чайковский, Римский-Корсаков, Джоплин) - `docs/music.md`.
- **Конвертер SID** (`studio/sid2yz.py`, `studio/sid/`): мелодии C64 в `.YZ`, с разбором того, что
  переносится, - `docs/SID.md`.
- **Модель движка** (`studio/pyplay.py`): тот же расчет, что в плеере, тик за тиком; по ней
  проверяется плеер на 6502.

## Быстрый старт

Нужны:
- Python 3 с numpy (matplotlib - для спектрограмм);
- рабочая копия eCat3 рядом (`../eCat3`) с собранным `eCat3-headless` или путь к ней в `ECAT3_DIR`
  (`docs/ecat3.md`).

AS65 (Win32) лежит в `third_party/as65`.

```
python studio/build.py                  диск симфонии -> dist/yazs-player.dsk и .hfe
python studio/build.py --set all        симфония и все пьесы -> dist/yazs-collection.dsk
python studio/build.py --set classics   переложения классики -> dist/yazs-classics.dsk
python studio/build.py --set demo       «Демо ЯЗС»: симфония, тур, свои пьесы -> dist/yazs-demo.dsk
python studio/listen.py m5_synth --mp3  одна мелодия: WAV/MP3 на скорости MAX, уровни, запас тика
python studio/listen.py файл.yz --mp3   то же для готового .yz
python studio/sid2yz.py мелодия.sid     мелодия C64 -> .yz (docs/SID.md)
python studio/checks.py                 все проверки (docs/development.md)
```

## Структура

| Каталог | Что |
|---|---|
| `player/` | плеер на 6502 (AS65); `gen_*.a65` генерирует `studio/build.py` |
| `studio/` | инструменты на Python: сборка, компилятор партитур, модель движка, диск 840 КБ, прослушивание, сверка, конвертер SID |
| `studio/score/` | партитуры, инструменты, помощники (аккорды, свинг, проверка гармонии) |
| `studio/importers/` | генераторы `score/data_*.py` из MIDI и LilyPond (переложения классики) |
| `studio/sid/` | конвертер SID: эмулятор 6502, окружение C64, разбор, перевод |
| `disk/` | шаблон диска 840 КБ: дорожка 0 с «Быстропускалкой» и ДОС 3.3 |
| `third_party/` | AS65 и тесты процессора Клауса Дормана |
| `tests/` | суммы собранных партитур (`checks.py`) |
| `experiments/` | архив опытов: «теплая» версия, сравнение с демо НКЛ, гармоники тона, варианты «Шмеля» |
| `docs/` | документация |
| `docs-external/` | не в git: схема ячейки, записи плат, исходные диски, ноты-источники, примеры SID (`docs/external.md`) |
| `dist/`, `out/` | не в git: собранные диски и промежуточные файлы |
