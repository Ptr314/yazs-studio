# Как писать мелодии

Партитура - модуль `studio/score/<имя>.py` с функцией `song()`. Она возвращает `compose.Song`:
инструменты, голоса на языке вроде MML, ударные, управляющие события. `Song.build()` раскладывает все
по строкам, режет на кадры, убирает одинаковые паттерны и собирает `.YZ`. Версия - 1, если мелодия
в нее помещается, иначе 2 (`docs/FORMAT.md`).

```python
from compose import Song
from instruments import LF, MF, HF, LOUD, HIT, HOLD, KIT6

def song():
    s = Song("НАЗВАНИЕ", "АВТОР", bpm=120, rows_per_beat=4, beats_per_bar=4, frame_bars=1)
    s.instrument("lead", "ЛИД", [HOLD | HIT | LOUD | LF | MF], vib=(16, 5, 2))
    s.voice(0, "@lead o4 l8 c d e f g a b > c | c2 r2 |")
    s.drums(5, "k8 r8 s8 r8 k8 k8 s4 |", KIT6)
    s.text(0, "ПОДПИСЬ НА ЭКРАНЕ")
    return s
```

Послушать: `python studio/listen.py имя --mp3`. На диск: `python studio/build.py --only имя --disk x.dsk`
или добавить в `SONGS`/`COLLECTION` в `build.py`.

## Язык голоса

| Запись | Что |
|---|---|
| `o4`, `>`, `<` | октава (C4 - до первой октавы), выше, ниже |
| `l8`, `l8.`, `l12` | длительность по умолчанию (12 - восьмая триоль), точки |
| `c#4.` | нота с длительностью и точкой (`#`/`+` диез, `-` бемоль) |
| `^16` | связка: прибавить длительность |
| `r` | пауза (нота отпускается) |
| `_e` | лига: без нового удара, со скольжением при `{porta}` |
| `q6` | гейт: отпустить через 6/8 длительности (`q8` - держать) |
| `@имя` | инструмент |
| `{vib 0x53}` | эффект в начале следующей ноты (имена - `compose.EFFECTS`) |
| `[...]3` | повтор |
| `\|` | черта такта: проверка, что такт полон |
| `; ...` | комментарий |

- **Ударные** (каналы 5 и 6) пишутся буквами набора (`instruments.py`: `KIT6`, `KIT7`) или номерами
  пресетов `=8:4`.
- **Управляющий канал (7):**
  - `set_tempo(строка, bpm)` - скорость строки подбирается так, чтобы тик был около 100 Гц;
  - `ritard(от, до, bpm0, bpm1)` - плавная смена темпа;
  - `swing(от, до, длинная, короткая)` - SPEED на каждой строке;
  - `text(строка, "...")` - подпись на экран, до 64 знаков, коды Агата (латиница и кириллица
    заглавные).
- **Прямо в строку:** `Song.put(канал, строка, команда)` ставит команду без MML. Так работает
  конвертер SID: одна строка - кадр SID.
- **Кадры разной длины:** `Song.build(bounds=[0, ..., всего])`.

## Инструмент

`s.instrument(имя, подпись8, регистр, rel=..., arp=..., pitch=..., vib=(задержка, скорость, глубина),
detune=..., meter=(пик, удержание, спад))`.

- **Регистр** - макрос значений D0-D5 по тикам (полосы, D3, D4, D5), держит последнее или повторяет
  с `reg_loop`. Отсюда wah, «фильтр», тремоло, акценты.
- **`rel`** - макрос после снятия ноты, по умолчанию - полосы без огибающей.
- **`arp`** - полутоны по тикам.
- **`pitch`** - приращения высоты в 1/16 полутона за тик: развертки, «лазеры», синт-барабаны,
  точное вибрато.
- **Палитра** - `instruments.add_standard()`: орган, струнные, щипковые, бас и другие.

## Помощники (`score/common.py`)

| Функция | Что |
|---|---|
| `chord`, `voicing`, `near` | аккорды по символам (`Dm7`, `A7b9`...), расположение у заданной верхней ноты |
| `baroque_strings` | струнный концерт в 5 голосов из `data_vivaldi_*`: инструменты, украшения, piano/forte |
| `arpeggio`, `oompah`, `walking` | арпеджио, «умпа», шагающий бас по гармонии |
| `harmonize` | второй голос по гармонии к мелодии |
| `tp`, `dshift` | транспозиция MML, сдвиг по ступеням лада |
| `shuffle` | восьмые свингом 2:1 (сетка кратна 3) |
| `check_harmony` | печатает ноты, которых нет в аккорде доли: так проверялось голосоведение |

## Приемы и грабли

- **Тик около 100 Гц.** Выше ~110 Гц при пяти каналах движок не укладывается. `pick_speed` выбирает
  скорость строки (тиков на строку) и N под темп.
- **Повторный удар** требует D4 = 0 на тик раньше: движок делает это сам для новой ноты. Лига
  (`_`) - без удара. Быстрые повторы одной ноты - новым ударом или `RETRIG`.
- **Полосу каждый тик не переключать**, особенно ВЧ: шина ВЧ - фильтр верхних частот, переключение
  щелкает. Так «шмель» трещал на быстрых пассажах (`docs/history.md`).
- **D3 - это +9..12 дБ.** Лид и бас с D3, аккомпанемент без. Три голоса с D3 и бочка `$08`
  перегружают смеситель; уровни проверять `listen.py`: пик, доля выше 0.89, дБ по секундам.
- **Огибающая.** D4 - щипок, D5 - плавная атака ~0.3 с, D4+D5 - удар с удержанием. D5 без D4 сразу
  после ноты тихий: конденсатору нужно ~0.25 с.
- **Ниже ~575 Гц тон импульсный, «носовой».** Бас на НЧ и с D3 звучит полнее; верх на НЧ почти
  синус.
- **СЧ+ВЧ у мелодии - ярко, но может быть пронзительно.** На C6 центр спектра ~2 кГц и 23% энергии
  выше 3 кГц; одна СЧ при той же громкости - ~1.1 кГц и 1% (`measure.py`). В Вальсе цветов скрипки и
  гобой на СЧ - так лучше. У Вивальди без ВЧ слушатели услышали «сплошные басы»: соло и скрипки I
  вернулись на СЧ+ВЧ. Еще теплее - НЧ+СЧ, но на ~5 дБ громче.
- **Высокий голос - на НЧ+СЧ.** Выше до2 полоса НЧ теряет громкость, на до3 НЧ+СЧ громче остальных
  полос (-18.7 дБ против -20..-24). Сопрано Сольвейг подняли на октаву: голос остался над
  аккомпанементом, только когда сам перешел на НЧ+СЧ, а одна виолончель потеряла D3.
- **Хорус** - два канала в унисон с расстройкой 0.3-0.6% (так звучит демо НКЛ). То же заменяет ШИМ
  при переводе SID.
- **Сетка.** Строк на долю столько, сколько нужно мелким длительностям:
  - 3 - свинг;
  - 8 - «Шмель»;
  - 12 - пунктир, триоли, форшлаги (Сольвейг);
  - 16 - 64-е мелизмы (Анитра);
  - 48 - 64-е и секстоли (Фея Драже).

  Чем мельче сетка, тем больше паттернов: Анитре понадобилось 248 из 256 (в v1).
- **Подписи** - не длиннее 64 знаков: `assert` в конце партитуры ловит длинные.

## Переложения из нот (`studio/importers/`)

Классика переводилась из открытых наборов. Ноты-источники лежат в `docs-external/notes-sources`
(`docs/external.md`), права - в `docs/music.md`.

| Скрипт | Что |
|---|---|
| `midi_dump.py` | дорожки MIDI: ноты в долях, темп, размер |
| `midi_bars.py` | MIDI по тактам: проверить разметку и ноты |
| `ly_parse.py` | подмножество LilyPond: `\relative`, аккорды, лиги, повторы и вольты |
| `gen_*.py` | источник -> `score/data_<имя>.py` (`CH[канал]` - MML по тактам, `RPB`, `BARS`) |
| `gen_flowers.py` | Вальс цветов: расшифровка скана клавира (`flowers_text.py`) -> развертка повтора, бас и аккомпанемент левой руки, оркестровка по разделам, арфа по кругу на 4 канала; `--compare файл.mid` - сверка с MIDI: мелодия и бас по тактам (раскатанные аккорды и форшлаги MIDI выравниваются), звуковысотные классы по долям (знак альтерации не у той ноты) |
| `gen_vivaldi.py` | «Времена года» (Mutopia): ноты из MIDI, трели, морденты, тремоло, стаккато и пометки - из партий LilyPond по порядку нот |

`studio/midi2mml.py`:
- `parse_midi` - ноты и программы по дорожкам;
- `reduce_voice` - сведение нескольких дорожек в один голос с приоритетом и транспозицией: верхний,
  нижний, k-й по высоте;
- `to_mml` - события в MML по тактам: привязка к сетке, разложение длительностей, смена
  инструментов.

Партитура (`score/<имя>.py`) берет `data_<имя>.py` и раскладывает по инструментам, темпу, подписям.
Четыре части Вивальди раскладывает один помощник `common.baroque_strings`: пять голосов концерта на
пять каналов, украшения - варианты инструмента (`@solo_t2` - трель на тон вверх, `_m1` - мордент,
`_r32` - тремоло повторным ударом в макросе регистра), piano - BUS без D3.

Порядок:
1. `python studio/importers/gen_anitra.py путь.mid` -> `score/data_anitra.py`.
2. `score/anitra.py` - оркестровка.
3. `listen.py anitra --mp3` - уровни, запас тика.
4. `checks.py --update` - записать сумму новой партитуры.
