# Текстовый вид `.YZ`

Мелодию `.YZ` можно разобрать в текст, поправить в любом редакторе и собрать обратно. Это для
небольших правок, пока нет редактора: нота, инструмент, эффект, темп, подпись, название.

Текст - уровня трекера, а не партитуры: кадры, строки, каналы, как в самом файле
(`docs/FORMAT.md`). Неизмененный текст собирается в тот же файл байт в байт (`checks.py`, шаг [1]).

## Как работать

С готовым диском плеера (`dist/*.dsk` или любым другим, где есть `ЯЗС-ПЛЕЕР`):

```
python studio/yzdisk.py ДИСК.dsk                          каталог: что в меню и под какими номерами
python studio/yzdisk.py ДИСК.dsk --extract "ИМЯ.YZ"       достать мелодию в ИМЯ.YZ
python studio/yztext.py ИМЯ.YZ                            -> ИМЯ.yzt рядом
    ... правка ИМЯ.yzt ...
python studio/play.py ИМЯ.yzt --disk ДИСК.dsk             играть в окне eCat3, работать в плеере
python studio/yzdisk.py ДИСК.dsk --add ИМЯ.yzt            на диск: то же имя заменяется
```

| Шаг | Что нужно |
|---|---|
| `yztext.py`, `yzdisk.py` | только Python: `compose.py`, `tables.py`, `mkdisk840.py`, `score/instruments.py`; без numpy, AS65 и eCat3 |
| `play.py --disk` | оконный eCat3 |
| `play.py` без `--disk`, `listen.py` | AS65 (плеер собирается заново) и eCat3; `listen.py` - еще numpy |
| `yzdisk.py --hfe` | консольный eCat3 (`.hfe` пишет он) |

Еще:

```
python studio/yztext.py m4_blues                    партитура score/ -> out/text/m4_blues.yzt
python studio/yztext.py ИМЯ.yzt                     -> ИМЯ.YZ рядом (перезаписывается)
python studio/yztext.py ИМЯ.yzt -o ДРУГОЙ.yz        куда писать
python studio/listen.py ИМЯ.yzt --mp3               WAV/MP3 на скорости MAX, уровни, потерянные тики
python studio/build.py --add ИМЯ.yzt --disk out/my.dsk --no-hfe
                                                    новый диск: симфония и эта мелодия
```

Текст - в UTF-8; при чтении метка BOM не мешает.

### Диск: `yzdisk.py`

- `--add` берет `.yz`, `.yzt` или имя партитуры, можно несколько. Имя на диске - имя файла
  заглавными, `_` заменяется на `-`, с `.YZ`; другое - `--name` (с одним `--add`).
- Файл с тем же именем заменяется и остается на своем месте в меню.
- Без `-o` правится сам образ, с `-o новый.dsk` - пишется новый.
- `--delete "ИМЯ.YZ"` удаляет мелодию. Защищенный файл (плеер) не удаляется и не заменяется.
- `--extract` достает `.YZ` как он был собран, и у v2 с блоками тоже.
- Плеер показывает двоичные файлы `*.YZ` в порядке каталога, до 40. В каталог шаблона входит 35
  файлов. О диске без плеера или с лишними защищенными файлами `yzdisk.py` предупредит.

### Окно eCat3: `play.py`

```
python studio/play.py ИМЯ.yzt --disk ДИСК.dsk [--frame N] [--menu] [--wait]
python studio/play.py ДИСК.dsk [--song N|"ИМЯ.YZ"] [--frame N]
```

Мелодия ложится на копию диска в `out/play/`, сам диск не меняется. eCat3 грузит машину
Агат-9 с ЯЗС на скорости MAX, выбирает мелодию в меню и включает ее в настоящем времени. Дальше -
клавиши плеера (`docs/player.md`, «Управление»):
- ВЛЕВО/ВПРАВО - кадр назад и вперед;
- R - повтор мелодии;
- ВВОД - пульт или трекер;
- ПРОБЕЛ/ВВЕРХ - следующая и предыдущая мелодия;
- РЕД - меню.

Ключи:
- `--frame N` - сразу перейти к кадру N;
- `--menu` - не запускать мелодию;
- у диска `.dsk` без `--song` остается меню;
- `--wait` - вернуться, только когда окно закроют. Без него `play.py` сразу возвращается, а окно
  остается.

Правка и прослушивание по кругу: поправили `.yzt`, закрыли окно, снова `play.py ... --frame N` с
кадра, где правка.

Оконный eCat3 ищется по порядку:
1. `ECAT3_EXE` - путь к `eCat3.exe`, как в `.mcp.json`;
2. выпуск в `ECAT3_DIR`: `eCat3.exe` рядом с `computers/`;
3. сборки `src/cmake-build-mcp`, затем остальные `src/cmake-build-*` в рабочей копии eCat3 (свежая
   первой).

Отдельному выпуску ничего не нужно: все файлы лежат рядом с exe. Сборке из `cmake-build-*`
`play.py` добавляет в `PATH` каталоги Qt и компилятора из ее `CMakeCache.txt`.

Свои настройки окно хранит в `out/play/work/ecat.ini`: громкость, размер окна и прочее переживают
перезапуски, а `ecat.ini` самого eCat3 не трогается.

## Пример

```
title    "ПРОВЕРКА ДВИЖКА"
subtitle "ВСЕ ЭФФЕКТЫ"
tempo    83   ; N таймера ЯЗС: тик 96.1 Гц
speed    12   ; тиков на строку: 8.0 строки в секунду

instrument 0 "ОРГАН"
  reg    HOLD+HIT+LOUD+LF+MF+HF
  rel    LOUD+LF+MF+HF
  vib    0 0 0
  detune 0
  meter  15 12 2

text 0 "НОТЫ И ИНСТРУМЕНТЫ"

frame 0 rows 16
;  | 1      | 2   | 3   | 4   | 5      | 6   | 7   | ctl
00 | C-4 @0 |     |     |     | C-2 @7 | 08  | 03  | {text 0}  ; "НОТЫ И ИНСТРУМЕНТЫ"
01 |        |     |     |     |        |     |     |
02 |        |     |     |     | C-2    | === | 03  |
04 | E-4    |     |     |     | G-2    | 0E  | 03  |
```

## Синтаксис

`;` - комментарий до конца строки (кроме `;` внутри кавычек). Пустые строки не важны.

### Заголовок

| Строка | Что |
|---|---|
| `title "..."`, `subtitle "..."` | название и вторая строка меню, до 30 знаков |
| `tempo N` | N таймера ЯЗС (1-255): тик 7980 / N Гц; как эффект `tempo` |
| `speed N` | тиков на строку (2-255); как эффект `speed` |
| `loop N` | кадр, с которого повторять; нет строки - без повтора |
| `version 2` | записать версию 2, даже если мелодия влезает в версию 1 |
| `main_limit N` | только для проверок v2: байт паттернов в основной части, остальное - в блоки |

Без `version` сборка выбирает версию сама, как `compose.py`: 1, если мелодия в нее помещается,
иначе 2. Длительность для меню считает сборка.

### Инструменты

```
instrument N "ИМЯ"            номера подряд с 0, имя до 8 знаков
  reg    значения [loop K]    макрос регистра по тикам
  rel    значения [loop K]    макрос отпускания
  arp    полутоны [loop K]    арпеджио, со знаком; нет строки - нет макроса
  pitch  доли [loop K]        макрос высоты, 1/16 полутона за тик; нет строки - нет макроса
  vib    задержка скорость глубина   глубина 0-15
  detune доли                 со знаком
  meter  пик удержание спад   индикатор
  flags  N                    резерв, обычно не пишется
```

Значение регистра:
- разряды D0-D5 по именам через `+`, как в `score/instruments.py`: `HF` (D0, ВЧ), `MF` (D1, СЧ),
  `LF` (D2, НЧ), `LOUD` (D3), `HIT` (D4, удар), `HOLD` (D5, удержание);
- можно числом: `0x3C`, `60`.

`loop K` - с какого значения макрос идет по кругу после последнего. Без `loop` держится последнее
значение. Без строки `rel` отпускание - полосы и D3 последнего значения `reg`.

### Подписи

`text N "..."` - подпись для эффекта `{text N}`. Номера подряд с 0.

### Кадры

`frame N rows R` - кадр из R строк (1-255). За ним строки сетки: номер строки, затем через `|`
ячейки каналов 1-5 (тоновые), 6, 7 (ударные) и ctl (управляющий).

- Строки - по возрастанию. Пустые можно не писать, а ячейки в конце строки - опускать.
- Кадры нумеруются по порядку с 0, по этому номеру считают `jump` и `loop`. Число в `frame N` -
  для глаз: если оно не совпало с местом кадра, сборка предупредит. Вставили кадр - поправьте
  `jump` и `loop`.
- `; как кадр 3` у кадра значит, что он такой же, как кадр 3. Сборка снова сольет одинаковые
  паттерны, а кадры правятся по отдельности.

Ячейка - слова через пробел, не больше одной ноты (или `===`):

| Слово | Что | Каналы |
|---|---|---|
| `C-4`, `C#4` | нота C0..B7 (C4 - до первой октавы, как `o4 c` в партитуре) | 1-5 |
| `_C-4` | лига: без нового удара; с `porta` - скольжением | 1-5 |
| `08`, `_08` | пресет ударного (D0-D3), hex | 6, 7 |
| `===` | отпустить (макрос отпускания) | 1-7 |
| `^^^` | заглушить сразу | 1-7 |
| `@N` | инструмент для следующих нот | 1-7 |
| `{имя p}` | эффект | все |

Эффекты (`docs/FORMAT.md`, «Эффекты»): `arp`, `su`, `sd`, `porta`, `vib`, `det`, `bus`, `trem`,
`delay`, `cut`, `speed`, `tempo`, `jump`, `text`, `tr`, `retrig`, `break`. Параметр - число
(`-8`, `12`, `0x46`). Если его нет, он равен 0.

Внутри строки порядок слов не важен: сборка, как и `compose.py`, ставит инструмент и эффекты до
ноты.

### Строки в кавычках

Знаки - из набора экрана Агата (`tables.py`): латиница, кириллица, цифры, знаки. `Ё` пишется как
`Е`. Кавычка - `\"`, обратная косая черта - `\\`. Код экрана без знака (псевдографика) -
`\xNN`.

## Ошибки

Сборка останавливается на первой ошибке и называет строку текста. Например:
- `строка 128: канал 1: нота E-9 вне C-0..B-7`;
- `строка 124: инструмента 99 нет (всего 15)`.

Проверяются:
- ноты и пресеты;
- номера инструментов и подписей;
- `jump` и `loop` в пределах кадров;
- `speed` не меньше 2;
- длина макросов: инструмент со всеми макросами - до 255 байт;
- что мелодия влезает в формат.

## Ограничения

- Правки в тексте не попадают в партитуры `score/*.py`. Для пьес проекта источник по-прежнему
  партитура, а текст - для тех, у кого есть только `.YZ`.
- Номеров паттернов в тексте нет: их раздает сборка. Мелодия, собранная не `compose.py`, может
  собраться с другим порядком паттернов и команд. Звучит она так же, и `yztext.py` об этом
  предупредит.
- Чисел инструментов и подписей в заголовке `.YZ` нет. Декомпилятор берет их из расположения
  таблиц, как их кладет `compose.py`.
- Переводы SID и в тексте остаются чужой музыкой: в репозиторий и на публикуемые диски их не класть
  (`docs/SID.md`).
