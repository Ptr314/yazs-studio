# Плеер

`player/*.a65`, AS65 1.42. Собирает `studio/build.py`: генерирует `gen_tables.a65` (периоды, вибрато,
строки экрана) и `gen_const.a65`, вызывает AS65, кладет плеер на диск. Рассчитан и на eCat3, и на
настоящий Агат-9 с дисководом 840 КБ.

| Файл | Что |
|---|---|
| `player.a65` | вход, переменные, нулевая страница, ячейка (запуск, тишина, таймер), ожидание тика |
| `engine.a65` | движок `.YZ`: кадры, разбор строк, эффекты, инструменты, высота (то же, что `studio/pyplay.py`) |
| `disk.a65` | драйвер 840 КБ, каталог ДОС 3.3, загрузка файла (с блоками v2) |
| `ui.a65` | меню, вид «пульт» (АЦР-32), подписи, время и кадр |
| `tracker.a65` | вид «трекер» (АЦР-64) |

## Диск

Дорожка 0 и ДОС 3.3 - из `disk/template840.dsk`. Там стоит «Быстропускалка» V2.0 (Ravodin, 2015):
если на диске ровно один защищенный двоичный файл, она запускает его сама, без ДОС. Этот файл -
`ЯЗС-ПЛЕЕР` (`$1800`). Мелодии лежат рядом незащищенными двоичными файлами `*.YZ`. Их можно
дописать на диск ИКП, DISK Commander или `fddconv`, плеер найдет все (до 48).

RTS в «Быстропускалку» снова запустил бы плеер, поэтому выход - в монитор (`jmp $FF65`).

## Управление

- **Меню:**
  - ВВЕРХ/ВНИЗ - выбор, ВВОД или ПРОБЕЛ - играть;
  - А - все подряд (по кругу), Д - перечитать каталог (другой диск);
  - ВЛЕВО/ВПРАВО - слот ячейки (1-6, по умолчанию 1);
  - РЕД - в монитор.
- **Во время игры:**
  - ВВОД - вид «пульт» или «трекер»:
    - пульт: инструмент, нота, уровень, полосы НЧ/СЧ/ВЧ и D3 каждого канала, регистры и периоды,
      подписи;
    - трекер: строки кадра, вспышка палитры на ударах;
  - ВПРАВО - следующий кадр, ПРОБЕЛ - следующая мелодия, РЕД - в меню.

## Память

| Адреса | Что |
|---|---|
| `$0000-$00FF` | нулевая страница плеера; при входе сохраняется в `$0400`, при выходе восстанавливается |
| `$0400-$0FFF` | сохраненная нулевая страница, переменные каналов (`$0500-$065F`), буферы диска, каталог (`$0A00`) |
| `$1000-$17FF` | экран (АЦР-32 / АЦР-64) |
| `$1800-$3EFB` | плеер |
| `$3EFC-$BFFF` | тело B-файла мелодии: 4 байта ДОС, `.YZ` с `$3F00`, до 32 КБ; у v2 с блоками основная часть - до `$9FFF` |
| банки 8-15 | блоки `.YZ` v2 по 8 КБ, видны в окне `$A000-$BFFF` |

`$D000+` («Быстропускалка» и монитор) плеер не трогает. Важные ячейки для отладки:
- `$1E-$1F` - счетчик тиков (сверяется с `yazs.irqs`);
- `$14` - кадр, `$7E` - его старший байт (v2);
- `$79-$7C` - наименьший запас тика за мелодию (проходы ожидания по ~22 такта) и тик, где он был;
- `$82` - банк в окне;
- `$05E8`, `$05F0`, `$05F8` - последний регистр и период каналов: их читает `verify.py`.

## Такт

- **Прерывания не используются:** SEI все время. Тик - опрос флага таймера ячейки (`+0`, D7) и сброс
  его командой защелки `$80` в `+7`.
- **Тики строки:**
  - в тике 0 строки движок читает команды всех каналов и готовит ноты; если звучащую ноту надо
    ударить заново, сбрасывает D4;
  - ноты и удары включаются в тике 1 (или позже, эффект `DELAY`). Так у каждого удара есть тик с
    D4 = 0, и все каналы опаздывают одинаково.
- **Долгая работа экрана** зовет `poll_tick`: если флаг взведен, тик играется посреди отрисовки
  (временные ячейки сохраняются).
- **Бюджет:** при пяти каналах тик выше ~110 Гц не укладывается (`compose.pick_speed` такого
  избегает). `speed = 2` при N = 80 (100 Гц), как у переводов SID, держит запас от ~1200 тактов.
- **«Потеряно N»** в `listen.py` - разница `yazs.irqs` и счетчика тиков. ±1 - дрожание снимка. Сотня
  тиков у больших файлов - загрузка с диска: таймер уже идет. `studio/lostticks.py` показывает
  потери по секундам.

## Загрузка и версия 2

`load_file` (`disk.a65`) идет по списку T/S файла и грузит сектора с `$3EFC` подряд.

У `.YZ` v2 с блоками (`docs/FORMAT.md`):
- **Разбор:** по первому сектору (заголовок) `yz_layout` узнает, где кончается основная часть (её
  длина + 4 кратна 256) и сколько блоков.
- **Блоки:** следующие сектора идут через окно `$A000-$BFFF`. Перед блоком k (1-8) - запись в
  `$C150 + банк`: сегменту 5 - банк 7 + k (8-15).
- **После загрузки** окно возвращается на банк 5.
- **При игре:** `load_frame` для каждого канала запоминает адрес паттерна и банк (`c_bank`).
  `parse_ch` переключает окно, если там не тот банк. Трекер перед разбором паттерна делает то же.

Без блоков v2 отличается от v1 только 16-битными номерами кадров и паттернов. Номер кадра на
экране - пять цифр.

## Диск 840 КБ

Свой драйвер (`disk.a65`):
- поле адреса и данных разбираются так же, как в загрузочном ПЗУ контроллера (`$C55C-$C5EA`);
- шаг головки (5 мс), успокоение (18 мс) и сторона - как у «Быстропускалки» (`$D7E1`);
- на поиск синхронизации и раскрутку мотора есть таймауты.

Порты (X = слот * 16):
- `+1` состояние привода: D4 индекс, D6 = 0 - дорожка 00, D7 = 0 - готов;
- `+2/+3` порт C и управляющее слово ВВ55: D2 направление шага, D4 сторона, D7 мотор;
- `+4` байт данных;
- `+6`: D6 = 0 - синхронизация, D7 = 1 - байт готов;
- `+9` шаг, `+A` сброс синхронизации.

## На настоящей машине

Для железа сделано:
- ячейка в слоте 1, чужие слоты не читаются;
- SEI и опрос флага; при старте `+F = $C0` и режим 3 всем шести счетчикам;
- пауза D4 = 0 не короче тика;
- `+F = $C0` на выходе, `$D000+` не тронут;
- шаг головки - по рабочему загрузчику.

На настоящем Агате-9 плеер пока не запускался: всё проверено в eCat3. Отдельно стоит проверить
переключение банков для v2 (`docs/roadmap.md`).

## AS65: на что наступили

- **`hi()` и `lo()` берут все выражение до конца:** `hi(WINDOW)+$20` = `hi(WINDOW+$20)`. Нужные
  страницы - константами (`WINPG`, `WINEND` в `player.a65`).
- **Короткие переходы - ±127 байт.** После вставки кода в `load_file` пришлось ставить мостики
  (`lf_e1`).
