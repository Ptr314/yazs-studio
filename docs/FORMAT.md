# Формат `.YZ` версий 1 и 2

Мелодия для ячейки звукового синтеза 5/2 (ЯЗС) Агата в трекерном виде: кадры, паттерны каналов,
инструменты с макросами по тикам, эффекты. Плеер (`player.a65`) играет его как есть, а будущий
редактор правит.

Версия 2 отличается только адресацией: 16-битные номера кадров и паттернов и паттерны в блоках
верхних 64 КБ ОЗУ (раздел «Версия 2»). Строки, команды, эффекты и инструменты у обеих версий одни и
те же. `compose.py` пишет версию 1, если мелодия в нее помещается, иначе версию 2.

На диске ДОС 3.3 файл записан как незащищенный двоичный (B) с именем `*.YZ`. Плеер загружает тело
файла так, что первый байт `.YZ` оказывается в `$3F00`. Все адреса внутри файла даны смещениями от
его начала, младший байт первым.

## Время

- **Тик** — период счетчика прерываний ЯЗС: 7980 / N Гц. N задается в заголовке и эффектом `TEMPO`;
  обычно 60-100, это 80-133 Гц.
- **Строка** длится `speed` тиков, `speed` не меньше 2.
- В тике 0 строки плеер читает команды всех каналов и готовит ноты. Если звучащую ноту надо ударить
  заново, он сбрасывает D4. Новые ноты и удары ударных включаются в тике 1 (или позже, эффект
  `DELAY`). Так у каждого нового удара D4 = 0 держится один тик: без этой паузы плата не дает
  акцента, а ударный не перезапускается. Все каналы опаздывают на один тик одинаково.

## Заголовок (80 байт)

| Смещ. | Размер | Что |
|---|---|---|
| 0 | 2 | `YZ` (`$59 $5A`) |
| 2 | 1 | версия, 1 или 2 |
| 3 | 1 | флаги: D0 — после конца можно повторять с кадра `loop` (плеер повторяет только по R) |
| 4 | 30 | название, коды экрана Агата, дополнено `$A0` |
| 34 | 30 | вторая строка (автор, часть), то же |
| 64 | 2 | длительность, секунды (для меню) |
| 66 | 1 | N — делитель таймера ЯЗС |
| 67 | 1 | `speed` — тиков на строку |
| 68 | 1 | число кадров (у v2 - младший байт, до 255; полное число - в 80) |
| 69 | 1 | кадр повтора (у v2 - младший байт или `$FF`; полный - в 82) |
| 70 | 2 | смещение таблицы кадров |
| 72 | 2 | смещение таблицы паттернов (слова-смещения) |
| 74 | 2 | смещение таблицы инструментов (слова-смещения) |
| 76 | 2 | смещение таблицы подписей (слова-смещения строк, строка кончается 0) |
| 78 | 2 | резерв |

У версии 2 заголовок 88 байт, за ним еще:

| Смещ. | Размер | Что |
|---|---|---|
| 80 | 2 | число кадров (до 65534) |
| 82 | 2 | кадр повтора (`$FFFF` - нет) |
| 84 | 2 | длина основной части `L`, байт (см. «Версия 2») |
| 86 | 1 | число блоков по 8 КБ (0-8) |
| 87 | 1 | резерв |

## Кадры

По 9 байт на кадр (у версии 2 - по 17):
- число строк кадра (1-255); кадры могут быть разной длины;
- номера паттернов каналов 0-7 (у версии 2 - по 2 байта, младший первым):
  - 0-4 — тоновые каналы 1-5 (счетчики ВИ53, регистры `+8..+C`);
  - 5, 6 — ударные (`+D`, `+E`);
  - 7 — управляющий канал (только эффекты).

Каналы могут ссылаться на один и тот же паттерн.

Таблица паттернов - по 2 байта на паттерн, смещение от начала файла. У версии 2 - по 3 байта:
смещение и блок. Блок 0 - основная часть, смещение от начала файла; блок 1-8 - смещение внутри
блока (0-8191).

## Паттерн

Поток команд, по строкам:

| Байт | Команда |
|---|---|
| `$00-$5F` | нота: 0 = C0 ... 95 = B7, с повторным ударом. В ударном канале — пресет 0-15 (D0-D3 регистра) |
| `$60` | отпустить (макрос отпускания) |
| `$61` | заглушить сразу (регистр канала 0) |
| `$62 i` | инструмент i для следующих нот |
| `$63 n` | нота n лигой: без нового удара; если задан `PORTA` — скольжением |
| `$64+e p` | эффект e с параметром p |
| `$80-$FF` | конец строки канала; следующие `b - $80` строк канал пропускает |

Строка канала без команд не занимает ничего: ее покрывает пропуск предыдущей. Сумма строк паттерна
равна числу строк кадра.

## Эффекты

Эффект действует, пока его не сменят. Исключения — `DELAY`, `CUT`, `JUMP`, `BREAK`: они только на
свою строку.

| e | Имя | p |
|---|---|---|
| 0 | `ARP` | xy: полутоны второй и третьей ноты, цикл 0, x, y по тикам; 0 — выкл. |
| 1 | `SLIDE_UP` | долей (1/16 полутона) за тик |
| 2 | `SLIDE_DN` | то же вниз |
| 3 | `PORTA` | скорость скольжения к ноте лиги, долей за тик (0 — сразу) |
| 4 | `VIB` | старшая тетрада — скорость (шагов из 64 за тик), младшая — глубина (доли); 0 — как у инструмента |
| 5 | `DETUNE` | расстройка, доли со знаком |
| 6 | `BUS` | D0-D3 регистра (полосы и D3) вместо инструментовых; `$FF` — как у инструмента |
| 7 | `TREMOLO` | период в тиках: первая половина как есть, вторая — без D5; 0 — выкл. |
| 8 | `DELAY` | нота этой строки включается на p тиков позже |
| 9 | `CUT` | через p тиков после включения ноты — отпустить |
| 10 | `SPEED` | тиков на строку (2-255) |
| 11 | `TEMPO` | N таймера (новый период со следующего) |
| 12 | `JUMP` | после этой строки — кадр p (0-255 и у версии 2) |
| 13 | `TEXT` | подпись p на экран (`$FF` — убрать) |
| 14 | `TRANSPOSE` | полутоны со знаком для этого канала |
| 15 | `RETRIG` | повторный удар каждые p тиков (0 — выкл.) |
| 16 | `BREAK` | после этой строки — следующий кадр |

Эффекты 10-13 и 16 глобальные, их можно ставить в любом канале.

## Инструмент

| Смещ. | Что |
|---|---|
| 0 | имя, 8 знаков экрана |
| 8 | флаги (резерв) |
| 9 | задержка вибрато, тиков |
| 10 | скорость вибрато (шагов из 64 за тик) |
| 11 | глубина вибрато, доли (0-15) |
| 12 | расстройка, доли со знаком |
| 13 | смещение макроса регистра от начала инструмента |
| 14 | смещение макроса отпускания |
| 15 | смещение макроса арпеджио (0 — нет) |
| 16 | смещение макроса высоты (0 — нет) |
| 17 | индикатор: старшая тетрада — пик, младшая — уровень удержания (0-15) |
| 18 | индикатор: спад за тик в 1/16 деления |

Макрос: `длина, повтор, значения...`. После последнего значения он идет с индекса `повтор`, а при
`повтор = $FF` держит последнее.
- **Регистр**: значения D0-D5 регистра канала — полосы, D3, D4, D5.
- **Отпускание**: то же, после `$60`.
- **Арпеджио**: полутоны со знаком к ноте.
- **Высота**: доли со знаком, которые прибавляются к высоте каждый тик (развертки, «лазеры»,
  синт-барабаны).

## Высота

Высота считается в долях полутона: `нота * 16`. К ней прибавляются скольжения, `PORTA` и макрос
высоты, транспозиция, расстройка инструмента и эффекта, арпеджио `* 16` и вибрато.

Период счетчика: `T[полутон * 16 + доля] >> октава` с округлением, где `T` — периоды нулевой
октавы при 1.021 МГц (`tables.py`). Счетчик пишется, только когда период изменился.

## Версия 2

Файл - основная часть длиной `L` (заголовок, таблицы кадров, паттернов, инструментов и подписей,
инструменты, подписи, паттерны, сколько поместится), за ней блоки по 8192 байта (последний может
быть короче). Паттерн целиком лежит или в основной части, или в одном блоке.

Как это лежит в памяти Агата-9 (128 КБ):
- основная часть, как и файл версии 1, - с `$3F00`;
- блок k (1-8) - в банке 7 + k (банки 8-15, верхние 64 КБ ОЗУ);
- плеер видит блок через окно `$A000-$BFFF` (сегмент 5). Диспетчер памяти переключает окно записью
  в `$C15B`: сегменту 5 - банк B. Перед чтением строки канала плеер ставит в окно банк его паттерна,
  если он там не стоит; основная часть - банк 5;
- поэтому основная часть файла с блоками кончается до окна: `L <= 24828`. `L + 4` кратна 256: с
  4 байтами заголовка B-файла ДОС блоки начинаются с начала сектора, и загрузчик грузит их
  секторами прямо в окно;
- без блоков основная часть может быть до 32 КБ, как у версии 1.

На диске это один B-файл ДОС 3.3. Его длина в заголовке B-файла - `L`: больше 64 КБ ДОС не
описывает. Плеер читает весь список T/S, а программы копирования (ИКП, DISK Commander) копируют все
сектора.

## Ограничения

- Версия 1: до 255 кадров, 256 паттернов, файл до 32 КБ (`$3F00-$BEFF`).
- Версия 2: до 65534 кадров и 65535 паттернов; основная часть до 24828 байт (без блоков - до 32 КБ),
  плюс до 8 блоков по 8 КБ: всего до ~88 КБ.
- Обе: до 256 инструментов, 256 подписей; инструмент со всеми макросами - до 255 байт.
