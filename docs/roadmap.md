# Что дальше

Порядок - примерный. Крупные пункты стоит начинать с плана.

## Ближайшее

- **Проверка на настоящем Агате-9:**
  - запуск плеера с «Быстропускалкой» и по `BRUN` из Бейсика с ДОС, выход обратно;
  - чтение диска 840 КБ своим драйвером (шаг головки, таймауты);
  - звук против eCat3;
  - переключение банков диспетчером памяти (`$C15B`) для v2 - пока проверено только на модели.
- **Диск со всеми пьесами для публикации** - после решения о правах на `ritz` (`docs/music.md`).
- **Запуск из ДОС:**
  - блоки v2 при ДОС: найти банки, которые не заняты ни ДОС (8-9), ни ее буферами (13...);
  - другие системы ИКП (Рапира, Ассемблер) - не проверялись.

## Формат и плеер

- **Чтение `.MUS` (драйвер SA-51)** в том же плеере и конвертер `.MUS -> .YZ`. Источники:
  - описание формата - форум agatcomp, pid=1286 (Voldemar0);
  - мелодии - `forum.agatcomp.ru/static_images/music.rar`;
  - дизассемблер PLAYERR (avivanov76) - в `muzcell.7z` плеера Tigoro;
  - MuzCell (Tronix286, GitHub).

  Сверять с записями с живой платы.
- **Графические виды** на экране Агата:
  - клавиатура, развертка нот, осциллограф (ЦГВР 256x256x4);
  - картинки частей: страница - любой 8-КБ банк.
- **Плеер как драйвер** для игр и демо: подключаемый движок без меню и диска, с API «играть
  мелодию / эффект».
- **Трекер на самом Агате.**
- **Формат:**
  - JUMP на кадр больше 255 в v2;
  - эффект BUS по строке для «развертки фильтра»;
  - макрос регистра длиннее 255 байт - если понадобится SID-конвертеру.

## ЯЗС-Студия на ПК

- **Редактор** (Qt или веб) со звуком точной модели ячейки. Ядро eCat3 без Qt есть и в WebAssembly:
  модель `agat_yazs.cpp` можно встроить или звать эмулятор через MCP/сценарии.
- **Экспорт** `.YZ`, `.dsk/.hfe`, WAV; **импорт** `.MUS`, MIDI (`midi2mml.py` уже умеет многое), XM/IT,
  SID (`sid2yz.py`).
- **Партитуры на Python** остаются основным текстовым форматом; редактор должен их читать или
  хотя бы собирать.

## Конвертер SID

- Развертка фильтра - сменой полос по строкам (эффект BUS с гистерезисом), а не одной на ноту.
- ADSR и общая громкость по строкам (BUS с D3) вместо одной огибающей на инструмент.
- Вибрато с перезапуском в лигах - макросом, перезапускаемым лигой (нужна поддержка в движке).
- Многоскоростные мелодии (2x - тик 100 Гц ложится ровно), окружение RSID (CIA, прерывания), мелодии
  на 2 SID (6 голосов на 5 каналов).
- Свой звук ударных из «таблиц волн» вместо пресетов (тон-канал + ударный).
- Отдельный путь - исполнять код SID на самом Агате: тот же 6502, `play` стоит 0.4-4.2 тыс. тактов
  на кадр. Мешают карта памяти (мелодии в `$C000-$FFFF`) и невозможность заглянуть вперед.
