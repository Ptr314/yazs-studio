# Эффекты и приемы: как они сделаны на ЯЗС

У тонового канала ЯЗС только две ручки:
- **период счетчика ВИ53** - высота;
- **регистр канала** `+8..+C`: D0-D2 полосы, D3 +12 дБ, D4 удар, D5 удержание.

У ударных - только регистр `+D`/`+E`. Каждый прием - это последовательность периодов,
последовательность значений регистра или их расстановка во времени. Движок меняет их раз в тик
(~100 Гц).

Здесь - механизм приемов и их пределы. Что делает каждый разряд физически, с замерами, - в
`docs/card.md`; поля формата - в `docs/FORMAT.md`; запись в партитуре - в `docs/composing.md`.
Механизм проверен по модели движка `studio/pyplay.py` (плеер на 6502 совпадает с ней тик в тик).

## Что движок делает за тик

1. **Тик 0 строки** - читает команды всех каналов. У канала, где будет новая нота, в этом тике
   снимается D4.
2. **Тик 1** (или `1 + p` при `DELAY p`) - нота включается: макросы инструмента с начала, отсчет
   задержки вибрато, фазы тремоло и повторного удара - с нуля. Лига (`$63`) макросы не
   перезапускает.
3. **Каждый тик, тоновый канал:**
   - регистр = очередное значение макроса регистра (после `$60` - макроса отпускания);
   - `BUS` подменяет D0-D3, D4 и D5 остаются от макроса;
   - `TREMOLO` во второй половине периода снимает D5;
   - `RETRIG` и ожидающая нота снимают D4;
   - регистр пишется, только если изменился.
4. **Каждый тик, высота** - в долях (1/16 полутона):
   - текущая высота: `PORTA` ведет ее к ноте лиги, `SLIDE` и макрос высоты прибавляются к ней
     накопительно;
   - к ней - `(TRANSPOSE + макрос арпеджио + ARP) * 16`, расстройка инструмента, `DETUNE` и вибрато;
   - период - из таблицы нулевой октавы со сдвигом на октаву (`tables.py`); счетчик пишется,
     только если период изменился.
5. **Ударные:** в тике 0 пишется пресет без D4, в тике 1 - с D4. Удар дает фронт D4.

## Высота: счетчики ВИ53

| Прием | Как сделан | Где слышно |
|---|---|---|
| Вибрато | синус из 64 шагов, глубина 0-15 долей; скорость - шагов за тик, задержка от начала ноты - у инструмента, `VIB` их перекрывает. Частота = тик * скорость / 64: при 100 Гц скорость 5 - 7.8 Гц. Фаза с нуля на каждой новой ноте, в лиге идет дальше | `tour`, почти все пьесы |
| Вибрато любой формы | макрос высоты с повтором: приращения по тикам | перевод SID (`docs/SID.md`) |
| Скольжение | `SLIDE_UP`/`SLIDE_DN p` - p долей за тик, двигают и ноту лиги. `su 4` - 1/4 полутона за тик, ~25 полутонов в секунду | `tour`, подъем перед дропом в `m5_synth` |
| Портаменто | `PORTA p` и лига: высота идет к ноте лиги по p долей за тик, без удара. Без `PORTA` лига переходит сразу | `tour`, лид `m5_synth`, глиссандо тромбона в `ritz` |
| Подъезд | макрос высоты `[-8, 2, 2, 2, 2, 0]`: нота начинается на полтона ниже и за 4 тика встает на место | медь и саксофоны `ritz`, `boogie` |
| Лазер | макрос высоты `[-24] * 14 + [0]`: -1.5 полутона за тик 14 тиков, дальше держит | `tour`, `m5_synth` |
| Синт-бочка | тоновый канал: НЧ, D4 и макрос высоты с убывающим шагом `[-48, -40, ..., -4, 0]` - вниз на ~11.5 полутона за 8 тиков | `tour` |
| Аккорд в одном канале | `ARP xy`: 0, x, y полутонов по тикам. При тике 100 Гц нота длится 10 мс, круг - 33 Гц: «чиптюн» | `tour`, бридж `m5_synth`, `ritz` |
| Арпеджио инструмента | макрос арпеджио: полутоны к ноте по тикам с повтором, например `[0, 4, 7]` | `test_fx` |
| Трель, мордент | макрос арпеджио: трель `[d] * 5 + [0] * 5` с повтором (с верхней ноты, по 5 тиков), мордент `[0] * 3 + [-d] * 3 + [0]` | Вивальди (`common.baroque_strings`) |
| Глиссандо по гамме | макрос арпеджио - ступени гаммы по 3 тика - и `RETRIG 3`: каждая ступень с ударом | фортепьяно `boogie` |
| Октавное тремоло | макрос арпеджио `[0] * 4 + [12] * 5 + [0] * 5`, повтор с 4, и `RETRIG 5` | фортепьяно `boogie` |
| Расстройка | у инструмента и `DETUNE`, доли со знаком | хорус (ниже) |
| Транспозиция | `TRANSPOSE` - полутоны для канала | `test_fx` |

Пределы:
- **Шаг высоты** - 1/16 полутона (6.25 цента). Счетчик различает все 16 долей до A7 (там один
  отсчет - 6 центов), на B7 - только 14 из 16.
- **Изменения - не чаще тика.** Вибрато идет ступенями, нота арпеджио короче 10 мс не бывает.
- **Ниже ~575 Гц тон импульсный, выше - меандр** (`docs/card.md`): скольжение через эту границу
  меняет и тембр.

## Огибающая и громкость: D3, D4, D5

Других громкостей у платы нет. Уровень задают D3 (+9..12 дБ), выбор огибающей и полосы
(`docs/card.md`, «Уровни и полосы»). Огибающие:
- D4 - щипок со спадом;
- D5 - плавная атака ~0.3 с и удержание;
- D4+D5 - удар с удержанием.

| Прием | Как сделан | Где слышно |
|---|---|---|
| Новый удар | движок снимает D4 в тике 0 и ставит в тике 1: пауза D4 = 0 не короче тика (плате нужно 10 мс). Лига - без удара | везде |
| Короткий акцент | D4 только в первом тике, дальше D5: `[reg \| D4, reg]`. На быстрых нотах слышна каждая | Вивальди |
| Поздний удар | макрос регистра: D5 без D4 несколько тиков, потом D4 - удар внутри ноты | «хор» `boogie`: 10 тиков НЧ на D5, затем удар на НЧ+СЧ |
| Ступень огибающей | D4+D5, затем один D5 - уровень ниже. Ставить не раньше ~0.25 с: до этого конденсатор D5 не заряжен и звук проваливается | - |
| Тремоло громкости | `TREMOLO p`: первая половина периода как есть, вторая без D5, RC ячейки сглаживает. Частота = тик / p. Работает только у инструмента с D5 | вибрафон `ritz` (`trem 16`, ~6 Гц), `tour` |
| Тремоло повторным ударом | `RETRIG p`: каждые p тиков D4 снимается на тик и макрос регистра идет сначала. То же без эффекта - макрос регистра `[reg \| D4] + [reg] * (p - 1)` с повтором | струнные `bumblebee` (`RETRIG 3`), Вивальди (`_r32`), фортепьяно `boogie` |
| piano/forte | `BUS` без D3 у партии, `BUS $FF` - вернуть | Вивальди |
| Отпускание | `$60` (пауза в MML) - макрос отпускания; по умолчанию полосы и D3 те же, D4 и D5 сняты: звук гаснет по RC (после D5 ~0.1 с). `$61` - регистр 0 сразу | везде |
| Стаккато | `CUT p` - отпустить через p тиков после удара; `q` в MML - через долю длительности (ставит `$60`) | `test_fx`, бас `tour` (`q6`) |

Пределы:
- **D5 без D4 сразу после ноты тихий** ~0.25 с.
- **D3 у трех голосов и бочка с D3 перегружают смеситель** (`docs/card.md`).
- **Ударный сбросом D4 не гасить:** модель eCat3 его так не гасит, плата по описанию гасит.

## Тембр: полосы D0-D2

| Прием | Как сделан | Где слышно |
|---|---|---|
| Выбор полос | у инструмента: НЧ (выше A4 почти синус), СЧ, ВЧ и сочетания; уровни разные (`docs/card.md`) | `tour` - все 7 сочетаний |
| Яркая атака | ВЧ или СЧ только в первых тиках макроса, дальше без них: одно переключение на ноту | фортепьяно и басы `boogie`, `ritz` |
| «Уа» | макрос регистра меняет полосы по ходу ноты: НЧ 6 тиков, потом НЧ+СЧ | тромбон `ritz` |
| Развертка «фильтра» | `BUS` по строкам или тактам: НЧ -> НЧ+СЧ -> СЧ -> СЧ+ВЧ, как движение среза. `BUS` меняет D0-D3, огибающая остается от макроса | арпеджиатор `m5_synth`, аккорды `ritz` (по тактам) |
| Быстрый «вау» | макрос регистра: ВЧ -> ВЧ+СЧ -> СЧ -> СЧ+НЧ -> НЧ за 5 тиков | `test_fx` |

Пределы:
- **Полосы не переключать каждый тик, особенно ВЧ:** шина ВЧ - фильтр верхних частот, переключение
  щелкает. «Шмель» трещал, пока у солиста была ВЧ (`docs/history.md`).
- **Нет плавного среза, резонанса, другой формы волны:** тон - меандр через ключ, полосы - три
  постоянных фильтра. Что из SID поэтому не переносится - `docs/SID.md`.

## Время

| Прием | Как сделан | Где слышно |
|---|---|---|
| Темп | тик 7980 / N Гц (`TEMPO`) и `speed` тиков на строку (`SPEED`). `set_tempo` подбирает оба так, чтобы тик был около 100 Гц | везде |
| Замедление, ускорение | `ritard`: `SPEED`/`TEMPO` каждые несколько строк | концовки, `boogie`, симфония |
| Свинг | `swing`: `SPEED` на каждой строке, долгая и короткая восьмая. Или `shuffle`: сетка кратна 3 строкам, восьмые 2:1 | `boogie`, `ritz`, `m4_blues`, `manouche` |
| Сдвиг ноты внутри строки | `DELAY p`: нота включается в тике `1 + p`. p не больше `speed - 2`, иначе нота не успеет в своей строке. Пока нота ждет, у звучащей ноты канала D4 уже снят | эхо `ritz` |
| Мелкие длительности | сетка строк на долю: 12 - триоли и форшлаги, 16-48 - мелизмы (`docs/composing.md`) | Сольвейг, Анитра, Фея Драже |
| Форма | `JUMP` - на кадр, `BREAK` - на следующий кадр | - |

## Приемы на нескольких каналах

| Прием | Как сделан | Где слышно |
|---|---|---|
| Хорус | два канала в унисон с расстройкой на 1/16-2/16 полутона (0.36-0.72%): два счетчика с чуть разными периодами дают биения. У демо НКЛ - 0.3-0.6%. Им же заменяется ШИМ при переводе SID | `tour`, `m2_adagio`, Вивальди (соло и скрипки I) |
| Эхо | копия голоса в другом канале позже и без D3: на 3 строки (`tour`), на пунктирную восьмую (`m5_synth`) или на 9 тиков через `DELAY` (`ritz`, ~90 мс) | `tour`, `m5_synth`, `ritz` |
| Аккорд | по ноте на канал или `ARP` в одном канале - освобождает каналы, но звучит «чиптюном» | везде |

## Ударные

- **Ударный 6** - тональный, 8 высот (D0-D2) и D3 - громче и дольше. **Ударный 7** - шум,
  4 высоты (D0-D1) и D3. Пресеты и что они звучат - `docs/card.md`.
- **Перезапуск** - только после тика с D4 = 0: движок делает его сам.
- **Свой ударный звук** - тоновый канал с макросом высоты (синт-бочка выше). Ударные из «таблиц
  волн» SID - в `docs/roadmap.md`.

Приемы демо ударных `sbivka` (12 строк на долю, скорость 4, тик ~93 Гц):

| Прием | Как сделан | Пределы |
|---|---|---|
| Бочка на тоновом канале | НЧ с D3, D4 9 тиков, потом без D4; макрос высоты вниз на 22 полутона за 13 тиков (A3 -> ~62 Гц); первый тик на НЧ+СЧ - щелчок атаки. Ударный 6 свободен под малый и очереди | одна дает пик ~0.77: бас с ней - без D3 |
| Томы на тоновых каналах | атака на НЧ+СЧ 3 тика, высота вниз на 9 полутонов за 18 тиков; два канала по очереди, чтобы удар не обрывал предыдущий | на время сбивки каналы аккордов заняты |
| Очередь («сбивка») | удар в каждой строке, 42 мс: быстрее нельзя, ударные бьют раз в строку (тик 1), `DELAY` и `RETRIG` у них нет. Оба шумовых канала вместе: ударный 6 (малый `$06`) отбивает каждый удар, ударный 7 чередует `$0B` и `$00` | ударный 6 с D3 в очереди - пик 0.96 |
| Пинг-понг | ударные 6 и 7 через строку | - |
| Разгон | промежутки 4-4-3-3-2-2-2-1-1-1-1 строки | - |
| Бочка очередью | тоновый канал, удар через 2 строки: макрос высоты каждый раз с начала и за 8 тиков успевает упасть на ~19.5 полутона из 22; в каждой строке (4 тика) - только на 13, звук выше | - |

В модели eCat3 ударный 7 сбросом D4 не гасится: ровная очередь `$03` сливается в шипение (провал
между ударами 3-5 дБ). Смена D3 с 1 на 0 дает глубокий провал, поэтому чередование `$0B`/`$00`
членит очередь через удар (~10 дБ). Живая плата, судя по записи «Сириуса», гасит сама
(`docs/card.md`).

## Цена в тактах

Каждый эффект высоты и каждый макрос стоят тактов в тике, а тик выше ~110 Гц при пяти каналах не
укладывается. Запас тика показывает `listen.py`. Диско перегружалось (запас 88 тактов), пока у
подклада не убрали вибрато (`docs/history.md`).

## Где слушать

- **`studio/score/tour.py`** - «Тур по тембрам»: по приему на такт, механизм - в подписи на экране.
- **`studio/score/test_fx.py`** - все команды и эффекты по разу. Сюда же - новые эффекты.
- **Пьесы-витрины:**
  - `m5_synth` - развертка `BUS`, `PORTA`, эхо, лазеры, `SLIDE_UP`, `ARP`;
  - `ritz` - «уа», подъезд, вибрафон с `TREMOLO`, эхо через `DELAY`, `ARP` с `BUS`;
  - Вивальди - трели, морденты, тремоло ударом, piano через `BUS`;
  - `boogie` - глиссандо и октавное тремоло фортепьяно, поздний удар хора.
