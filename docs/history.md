## 2026-11-04: SID, версия 2, отдельный проект

- **Разбор SID:**
  - 8 PSID-примеров;
  - свой эмулятор 6502 на Python (тесты Дормана), снятие регистров, сводка того, что каждая мелодия
    использует;
  - пробный конвертер, затем перенос в `tools/yazs-player` с описанием `SID.md`.

  Найдено:
  - арпеджио и вибрато точно ложатся в макросы инструментов;
  - ШИМ, развертки фильтра, RING/SYNC непереносимы;
  - D3 по умолчанию перегружает.
- **Формат v2:** 16-битные номера кадров и паттернов, паттерны в блоках по 8 КБ в банках 8-15 через
  окно `$A000`. Поводом стал хорус на басу Хаббарда - 296 паттернов. v1 собирается байт в байт как
  раньше. Плеер на 6502 сверен с моделью на v1 и v2 с блоками. В eCat3 пересобран диск библиотеки и
  перезаписаны два эталона теста: загрузка стала на 2 тика дольше.
- **Перенос:** все вынесено в отдельный проект ЯЗС-Студия
  (`https://github.com/Ptr314/yazs-studio`): плеер в `player/`, инструменты в `studio/`, знания - в
  `docs/`. В eCat3 остались модель ячейки, машина, диск библиотеки и его тест (`docs/ecat3.md`).
  Сборка из нового проекта дает образ, байт в байт равный диску библиотеки eCat3.

## Чему научились (кратко)

- Повторный удар на ЯЗС - только после D4 = 0 на тик.
- Тик выше ~110 Гц при пяти каналах не укладывается.
- Полосы не переключать каждый тик, особенно ВЧ.
- Три голоса с D3 и бочка с D3 перегружают смеситель.
- В AS65 `hi(X)+n` - это `hi(X+n)`.
- Python-патчи на Windows без `newline="\n"` переписывают файл с CRLF целиком.
- Heredoc в Bash портит обратные косые и кавычки: скрипты - файлами.
