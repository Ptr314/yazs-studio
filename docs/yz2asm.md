# Встраиваемый плеер для игр: `yz2asm.py`

`studio/yz2asm.py` превращает мелодии `.YZ` игры в один текстовый файл для ассемблера: плеер и
данные. Игра включает его в свою сборку и зовет мелодию одной командой: `jsr yz_title`. Звук
совпадает с ЯЗС-Студией тик в тик. Формат выбран замерами вариантов (`experiments/embed/README.md`):
на наборе мелодий он самый компактный, 11 джинглов Alice in Wonderland вместе с плеером занимают
1.2 КБ.

## Быстрый старт

```
python studio/yz2asm.py title=music/title.yz death=death.yzt m4_blues -o music.a65
```

- **Мелодия:** файл `.yz`, текстовый вид `.yzt` или партитура `score/<имя>.py`.
- **Имя входа:** `<префикс><имя>`, по умолчанию `yz_` и имя файла. Выше получатся `yz_title`,
  `yz_death`, `yz_m4_blues`.
- **Вывод:** размеры и итог проверки. Готовый текст сразу собирается AS65 и проигрывается на эмуляторе
  6502 против модели движка (`pyplay.py`).

В игре:

```
            include "music.a65"     ; плеер, словари, мелодии - одним куском, адрес любой
            ...
            jsr yz_title            ; играет до конца и возвращается
```

## Вызов

- **`jsr <вход>`** играет мелодию до конца и возвращается.
  - Портит A, X, Y. Флаги, в том числе I и D, восстанавливаются (PHP ... PLP).
  - Звуковые эффекты устроены так же, как мелодии.
- **Прерывания** на время звука запрещены (SEI). Игра стоит, тик плеер ждет опросом флага таймера
  ячейки. NMI не запрещается: обработчик игры не должен трогать ячейку и переменные плеера.
- **Ячейка** - слот `--slot` (1 - `$C090`).
  - Каждый вызов: стоп счета, тишина, режим 3 всем счетчикам, таймер N, пуск.
  - Выход: тишина, `+F = $C0`, флаг сброшен.
  - После конца мелодии плеер, как и Студия, секунду (100 тиков) дает нотам отзвучать.
- **Память:**
  - нулевая страница (`--zp`): 6 байт и по 2 на канал, еще по 2 на канал, если есть фразы. Всего
    8-34 байта, у Alice 14;
  - ОЗУ переменных (`--ram`): 20 байт на канал (22, если есть лиги), у Alice 40;
  - стек - 8 байт сверх адреса возврата.

  Размеры печатаются при сборке и пишутся в шапку файла. Нужны они только во время звука, после
  выхода игра пользуется ими как хочет.
- **Выход по клавише** (`--key`): после нажатия плеер выходит на ближайшем тике. Код клавиши
  остается в `$C000`, его читает игра, строб сбрасывает она же (`$C010`).
- **Адрес не важен.** Ассемблер игры ставит плеер и данные где угодно, можно с нечетного адреса.
  Код себя не меняет. Готовый образ с адреса `--org` дает `--bin`.
- **Весь кусок - ниже `$C000`.** Выше - ввод-вывод и ПЗУ, оттуда плеер прочтет не свои байты.
  Длинная мелодия велика: m4_blues с плеером - 18 КБ, с `$8000` она заходит за `$C000`.
  `yz2asm.py` проверяет образ с `--org` (по умолчанию `$4000`): он должен кончаться ниже `$C000` и
  не перекрывать переменные `--ram`.

## Ключи

| Ключ | Что |
|---|---|
| `-o файл` | выход (`yzmusic.a65`) |
| `--prefix p_` | префикс всех имен (`yz_`): ни одно имя плеера не пересечется с метками игры |
| `--slot n` | слот ЯЗС (1) |
| `--zp $xx`, `--ram $xxxx` | начало переменных (`$10`, `$0900`) |
| `--key` | выход по клавише (+5 байт) |
| `--save-zp` | плеер сохраняет свои ячейки нулевой страницы в ОЗУ переменных и восстанавливает на выходе (+20 байт кода, +размер нулевой страницы в ОЗУ): вызов из Бейсика, «Вызов из Бейсика» ниже |
| `--no-tail` | без секунды отпускания после конца: не как у Студии, последняя нота обрывается; у Alice -33 байта |
| `--no-phrases` | не искать повторы (быстрее сборка, больше данные) |
| `--plain` | без комментариев (текст только ASCII) |
| `--bin файл --org $xxxx` | еще и собранный образ |
| `--no-check` | без проверки на 6502 |
| `--ecat3` | еще и проверка в eCat3 (консольная сборка, `docs/ecat3.md`): игра со всеми входами подряд на диске с «Быстропускалкой», снимки регистров против модели |

## Вызов из Бейсика и демо-диск

Бейсик-А9 - потомок Applesoft: та же нулевая страница (программа с `$1901` в `$67`, HIMEM в
`$73`, CHRGET с `$B1`) и те же токены. Мелодию можно звать прямо из программы:

```
10 HIMEM: 32768: D$ = CHR$(4): PRINT D$;"BLOAD MUSIC.BIN"
20 CALL 33516: POKE 49168,0
```

- **Сборка:** `yz2asm.py ... --org $8000 --bin music.bin --save-zp --key`. Свободного куска нулевой
  страницы нужной длины у Бейсика нет, поэтому плеер на время звука берет любые ячейки и
  возвращает их. Прерывания в это время запрещены, Бейсик стоит.
- **`HIMEM:`** ставится на начало образа, иначе строки Бейсика растут сверху вниз прямо в него.
  Переменные плеера (`--ram`) тоже выше HIMEM, например `$BF00`.
- **Адреса входов** `yz2asm.py` печатает при сборке: «вход $82EC».
- **После стопа клавишей** `POKE 49168,0` сбрасывает строб, чтобы клавиша не ушла в `INPUT`.

`studio/yzdemo.py` делает из мелодий демо-диск на системном диске ИКП Агата-9 (`ikp1-16414.dsk` из
eCat3):

```
python studio/yzdemo.py alice01=a.yz alice02=b.yz ... -o dist/alice.dsk --name ALICE --title "Алиса" --ecat3
```

- **На диске:**
  - копия ИКП;
  - `<ИМЯ>.BIN` - образ с `--org` (`$8000`);
  - `<ИМЯ>` - программа на Бейсике-А9: `HIMEM:`, `BLOAD`, меню с длительностью и адресом входа
    каждой мелодии (шестнадцатеричным и десятичным), номер - `CALL` адреса, клавиша - стоп, 0 -
    выход.
- **Рядом:** `.hfe` (пишет eCat3) и `.a65` - текст для ассемблера.
- **На Агате:** ИКП -> «Бейсик», `RUN <ИМЯ>`.
- **`--ecat3`** проверяет диск (и `.hfe`) в eCat3:
  - `RUN`;
  - самая короткая мелодия играет до конца: тиков таймера столько же, сколько у модели вместе с
    отзвуком;
  - самая длинная останавливается клавишей;
  - выход, после него Бейсик работает.

  Снимки экрана - в `out/yzdemo/`.

Программу на Бейсике токенизирует `studio/agatbasic.py`. Таблица токенов взята из DISK
Commander (`dsk_tools/src/bas_tokens.h`). Строки, `DATA` и `REM` Бейсик хранит кодами Агата с
перевернутым старшим разрядом:
- латиница и цифры - 7-битный ASCII;
- заглавная кириллица - `$60-$7F`;
- строчная - `$E0-$FF`.

При выводе разряд возвращается. Набор через `TYPE` eCat3 так не годится: он теряет регистр
кириллицы и, если строки идут подряд без паузы, проглатывает знаки. Экран Бейсика - 32 знака в
строке. `$` в шрифте Агата - `¤`.

## Что берет плеер

Модель движка прогоняется по мелодии, а события раскладываются по тикам. Поэтому без всякого
кода в плеере передаются:
- кадры, `SPEED`, `JUMP`, `BREAK`;
- `TRANSPOSE` и `DETUNE` до ноты;
- подписи `TEXT` (они пропускаются);
- повтор с кадра `loop` не делается: вызов должен вернуться.

В плеер входит только то, что есть в мелодиях игры:

| В мелодии | В плеере |
|---|---|
| ноты, паузы, инструменты (огибающие регистра и отпускания) | всегда |
| отпускание `===`, гейт `q`, эффект `CUT` | `$F3` |
| заглушение `^^^` | `$F4` |
| лига без `PORTA` | `$F5` |
| `TEMPO` | `$F6` |
| высота меняется внутри ноты: скольжения, `DETUNE` по строкам, вибрато, арпеджио, `PORTA`, макросы высоты | `$F7` - период из словаря в этот тик |
| ударные 6 и 7 | ветка ударного канала |
| повторяющиеся куски потоков, в том числе между мелодиями | фразы: вызов и возврат |

Не берет (компилятор называет мелодию, тик, кадр, строку и что в ней есть):
- **эффекты регистра:** `BUS`, `TREMOLO`, `RETRIG`;
- **`DELAY`**;
- **изменение высоты в секунду отпускания после конца** - обычно вибрато на отпускании.
  Собирается с `--no-tail`;
- **больше 256 разных периодов на игру.** Так бывает при вибрато и арпеджио на многих нотах:
  Saboteur II, Spellbound Dizzy;
- **больше 16 инструментов** (разных огибающих) на игру.

Эффект высоты, расписанный по тикам, стоит 2-3 байта на каждое изменение. Мелодия, где вибрато
звучит почти все время, выходит больше своего `.YZ`: Legend Intro - 6.1 КБ против 4.7.

## Что в файле

- **Шапка:** входы с длительностями, адреса ячейки и переменных, возможности сборки.
- **Константы** (`equ`) и **плеер** - шаблон `player/yzplay.a65` без ненужных частей.
- **Общие данные:** каналы, словарь периодов, длительности, инструменты, общие фразы.
- **Мелодии:** вход (`jsr yz_play`), адреса потоков каналов, потоки, свои фразы.

Синтаксис - AS65 (им проверяется). Используются только метки с начала строки, `equ`, `db`, `dw`,
выражения с `+ - *` и команды 6502 (`lsr a` - с явным `a`). Условной сборки, макросов,
`lo()/hi()` и выравнивания нет. Для другого ассемблера хватает замены директив, например
`db` -> `.byte`, `dw` -> `.word`, `equ` -> `=`.

## Поток канала

Данные мелодии: N таймера (если у мелодий игры он разный) и по слову на занятый канал - адрес
потока. Каналы, которых в мелодии нет, а в игре есть, получают поток из одних пауз.

| Байт | Команда |
|---|---|
| `ddd nnnnn` (`$00-$DF`) | нота `nnnnn` (31 - пауза) длительностью `yz_durt[ddd]` тиков (7 самых частых в игре). Тоновый канал: индекс словаря периодов; ударный - пресет |
| `$E0+i` | инструмент i следующих нот |
| `$F0 n d` | нота n (31 - пауза), d тиков |
| `$F1 адрес` / `$F2` | вызов фразы / возврат (один уровень) |
| `$F3` / `$F4` | отпустить / заглушить; у ударного - пресет с D4 = 0 |
| `$F5` | следующая нота - лигой, без удара |
| `$F6 N` | таймер N |
| `$F7 n` | период n словаря сейчас, без удара |
| `$FF` | конец мелодии (только в первом потоке) |

Длительность считается до следующего разбора канала, пауза ничего не меняет. Удар происходит через
тик после разбора, и в тик разбора у звучащей ноты D4 = 0 - как у движка Студии. Инструмент:
смещение огибающей отпускания, затем пары (тиков, значение регистра), конец - (0, смещение пары
повтора).

## Проверки

- **Модель плеера** (`Game.simulate`) сверяется с моделью движка до записи файла, тик в тик, по
  множествам записей в счетчики, таймер и каналы. Там же она находит, где нужны команды периода
  (`$F7`).
- **Прогон на 6502** (по умолчанию): готовый текст собирает AS65, и каждая мелодия играет на
  эмуляторе 6502 конвертера SID. С `--key` проверяется еще и выход по клавише.
- **`--ecat3`:** все мелодии подряд в eCat3 на модели ячейки. Проверено на 11 мелодиях Alice и
  на тестовом наборе: 0 расхождений, число тиков таймера равно модели.
- **`checks.py`, шаг 6:** наборы из `score/test_embed.py`, у каждого свои возможности плеера:
  - все возможности вместе;
  - только ударные;
  - один тоновый канал;
  - лиги и период без `TEMPO`;
  - вибрато без хвоста;
  - без хвоста и без комментариев.

  Ошибка, которая видна только при части возможностей, ловится здесь.

## Правка плеера

- Шаблон `player/yzplay.a65` и его модель `Game.simulate` в `yz2asm.py` правятся вместе. Потом -
  `checks.py --quick` (шаг 6) и, если менялось время или запись в ячейку, `--ecat3`.
- **Флаги `F_*`** выбирает `Game` по потокам игры. Строки `if/else/endif` шаблона разрешает
  `preprocess()`. Новая часть шаблона под флагом должна собираться при любом сочетании остальных
  флагов. Метка внутри `if`, на которую ссылаются из другого блока, - частая ошибка: так было с
  лигой без `TEMPO`.
- **Имена** в шаблоне начинаются с `yz_`, `--prefix` меняет их все.
- Код плеера в выдаче взят из `player/yzplay.a65` и подпадает под лицензию проекта
  (GPL-3.0-or-later).
