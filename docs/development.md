# Разработка: проверки и отладка

## Проверки

```
python studio/checks.py            все: партитуры, v1/v2, процессор SID, плеер в эмуляторе, запуск из ДОС (~40 с)
python studio/checks.py --quick    без эмулятора и тестов процессора (секунды)
python studio/checks.py --update   записать суммы партитур после намеренной правки
```

1. **Суммы партитур** (`tests/scores.md5`): каждая `score/*.py` собирается в те же байты. Правка
   `compose.py`, инструментов или помощников не должна молча менять мелодии. Новая партитура - в
   отчете как «новая», запишется с `--update`.

   Там же - **текстовый вид** (`yztext.py`): каждая `.YZ` и блюз в v2 с блоками разбираются в текст
   и собираются обратно байт в байт.
2. **`test_v2.py`**: каждая партитура в v1 и в v2 с паттернами в блоке дает в модели (`pyplay.py`) те
   же записи в ячейку.
3. **`sid/test_cpu.py`**: эмулятор 6502 конвертера SID проходит тесты Дормана. Функциональный - как
   есть; десятичный пересобирается для NMOS, флаги N, V, Z - как у 6502.
4. **`verify.py`** в eCat3: плеер на 6502 против модели по регистрам и периодам каналов, на `test_fx`
   (все команды и эффекты) и на блюзе в v2 с блоком.
5. **`brun.py`** в eCat3: запуск плеера двумя путями и выход к запустившему (`docs/player.md`,
   «Запуск»):
   - «Быстропускалка»: после РЕД плеер вышел и запущен снова (метка в `dosmode` стерта входом);
   - ДОС: ИКП -> «Бейсик», `BRUN`, игра v1 и v2, мелодия с блоками - «не помещается», РЕД;
   - ОЗУ ДОС (банки 8-9), Бейсика (языковая карта) и его переходники `$1800-$18FF` - те же, что до
     `BRUN`;
   - Бейсик: `POKE`, `NEW`, программа и `RUN` (результат - в памяти), `CATALOG`, повторный `BRUN`.

   Нужен системный диск ИКП eCat3 (`deploy/software/agat/ikp1-16414.dsk`), иначе шаг пропускается.

## Инструменты отладки

| Команда | Что |
|---|---|
| `python studio/listen.py модуль\|файл.yz\|файл.yzt [--mp3]` | диск с одной мелодией, WAV на скорости MAX, уровни по секундам, пики, запас тика, потерянные тики |
| `python studio/verify.py модуль\|файл.yz [снимков] [шаг_мс]` | плеер против модели тик в тик |
| `python studio/verify.py диск.dsk файл.yz ...` | то же для готового диска (мелодия - первая в меню) |
| `python studio/brun.py` | запуск из «Быстропускалки» и по `BRUN` из ДОС, выход к запустившему (~7 с) |
| `python studio/lostticks.py модуль\|файл.yz` | потерянные тики по секундам: перегруз или загрузка |
| `python studio/shots.py модуль\|файл.yz\|диск.dsk` | снимки меню, пульта и трекера |
| `python studio/pyplay.py файл.yz [тиков]` | модель движка без эмулятора |
| `python studio/yztext.py файл.yz\|модуль\|файл.yzt` | текстовый вид `.YZ`: разобрать в текст и собрать обратно (`docs/text-format.md`) |
| `python studio/yztext.py --check [модули]` | `.YZ` -> текст -> `.YZ` байт в байт на партитурах |
| `python studio/yzdisk.py диск.dsk [--add\|--delete\|--extract ...]` | мелодии на готовом диске плеера без AS65: дописать, заменить, удалить, достать |
| `python studio/play.py файл.yzt\|файл.yz\|модуль\|диск.dsk [--disk готовый.dsk] [--frame N]` | мелодия в оконном eCat3: загружена и играет, дальше - клавиши плеера |
| `python studio/measure.py [каталог]` | замер палитры: все сочетания полос, D3, огибающих, ударные |
| `python studio/spectro.py a.wav от до a.png` | спектрограмма с нотной сеткой |
| `python studio/mkdisk840.py диск.dsk` | каталог диска |
| `python studio/sid2yz.py x.sid --stat / --frames В:С:N` | что использует мелодия SID, покадровые регистры |
| `python studio/sidcompare.py x.sid [--wav эталон.wav] [--yz версия.yz]` | перевод SID против записи настоящего звука: спектрограммы, сходство нот и спектра по 5 с (`docs/SID.md`, «Сверка с эталоном») |

Все, что гоняет эмулятор, пишет в `out/` (не в git). Живая отладка через MCP - `docs/ecat3.md`.

## Порядок правок

- **Движок** (новый эффект, поле инструмента):
  1. `studio/pyplay.py` (модель);
  2. `player/engine.a65`;
  3. сверка: `verify.py` на `test_fx` и мелодии, где эффект есть;
  4. `docs/FORMAT.md`;
  5. если поле новое, `compose.py`.

  `test_fx.py` стоит дополнить новым эффектом.
- **Формат:**
  - v1 не менять: старые файлы на дисках должны играть;
  - новое - через версию (байт 2 заголовка) и проверки в `eng_start`/`load_file`;
  - `compose.py` по-прежнему пишет самую младшую подходящую версию.
- **Компилятор партитур:** `checks.py --quick`. Изменились суммы, а музыка не должна была -
  ищите ошибку; должна была - `--update` и прослушать.
- **Плеер (интерфейс, диск):**
  - размер плеера - до `$3EFB` (`build.py` проверяет; загрузчик копирует тело страницами, хвост
    последней затирает мелодия). Таблицы `gen_tables.a65` выровнены по странице: размер тела растет
    скачками по 256 байт, когда код перед ними переходит границу (`docs/player.md`, «AS65»);
  - нулевая страница занята до `$86` (`player.a65`, `tracker.a65`);
  - переменные каналов - `$0900-$0A5F` (адреса `c_lreg`, `c_lperlo`, `c_lperhi` читает
    `verify.py`);
  - память ДОС: `$0300-$05FF` не трогать, `$0600-$0FFF` и страница `$18` - только с сохранением
    (`docs/player.md`, «Запуск»); `dos_exit` - вне страницы `$18`;
  - короткие переходы ±127 байт: длинный цикл - мостик через `jmp` (`pl_more`, `lf_e1`).
- **Запуск из ДОС:** после правки входа, выхода или памяти плеера - `brun.py` (он же шаг 5
  `checks.py`). Изменения в `$0300-$0FFF` после выхода он только показывает: туда пишет и сама ДОС
  (буфер имени, рабочие ячейки), обычно 40-45 байт в каждой из двух зон.
- **Диск библиотеки eCat3:** `build.py --to-ecat3` и тест в eCat3 (`docs/ecat3.md`).

## Окружение

- Python: на машине разработчика `C:\DEV\venv\Scripts\python.exe` (numpy, scipy, matplotlib,
  Pillow).
- AS65 1.42 (`third_party/as65/as65.exe`) - Win32. На Linux/macOS - через Wine, или другой ассемблер
  с тем же синтаксисом (не проверялось).
- eCat3 - рабочая копия рядом, консольная сборка (`docs/ecat3.md`).
- Окончания строк - родные для системы: на Windows CRLF, на Linux и macOS LF; в репозитории - LF
  (`.gitattributes`, `* text=auto`). Python-скрипты пишут текст без `newline=`: так файл выходит с
  родными окончаниями.
