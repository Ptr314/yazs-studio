# Шаблон диска

`template840.dsk` - образ 840 КБ Агата (160 логических дорожек по 21 сектору, ДОС 3.3) без файлов:
- дорожка 0 - загрузчик «Быстропускалка» V2.0 (Ravodin, 2015). Если на диске ровно один защищенный
  двоичный файл, она запускает его сама, без ДОС;
- ДОС 3.3: VTOC в T17 S0, каталог.

Сделан из `soundtest.DSK` (форум agatcomp, `docs/external.md`) удалением программы SOUNDTEST, так же,
как это раньше делал `build.py` при каждой сборке. Поэтому диск из `studio/build.py` совпадает байт в
байт с прежними сборками и с диском библиотеки eCat3.

`studio/build.py` (`blank_disk`) кладет на копию шаблона плеер `ЯЗС-ПЛЕЕР` (защищенный, `$1800`) и
мелодии `*.YZ`, ставит метку тома «ЯЗС-ПЛЕЕР». Каталог образа: `python studio/mkdisk840.py
disk/template840.dsk`.

Загрузчик и ДОС - чужие программы для Агата, распространяемые сообществом agatcomp вместе с дисками.
Тот же загрузчик уже лежит на диске `yazs-player.dsk` в библиотеке eCat3.
